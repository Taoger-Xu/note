# CMU Agent · AI Agents

CMU 11-768，围绕基于大语言模型的智能体，学习推理、规划、工具使用与多步交互。

## 课程资料

- [课程官网](https://www.cmu-agents.com/)

## 课程说明

本课程研究基于大语言模型（LLM）的 AI 智能体（Agent）。这类系统利用大语言模型进行感知、推理、规划，并在多个步骤中采取行动。智能体通过与环境交互来完成真实任务，包括调用工具、操作界面、编写代码以及与人协作。

课程既涵盖构建智能体的基础知识，也涉及长程推理、训练、安全性和交互等前沿研究问题。课程注重使用现代框架进行动手实践，并讲授能让智能体更强大、更可靠的训练方法。

## 基础部分：Agent 的核心能力

一个 Agent 要完成真实任务，需要四种能力：能**行动**（调用工具）、能**记住当前任务的上下文**（上下文管理）、能**积累经验**（技能与记忆）、能**拆解并协作完成复杂任务**（规划与多智能体）。课程的基础部分按这四种能力组织。

### Agent Capabilities 1: Tool Use

**核心问题**：LLM 本身只能生成文本，如何让它通过工具作用于外部环境？

- Agent 的基本循环：观察（Observation）→ 思考（Reasoning）→ 行动（Action）
- 工具的定义与调用：函数签名、参数 Schema、Function Calling
- ReAct：把推理与行动交替进行
- 常见工具类型：搜索与检索、代码执行、API 调用、浏览器 / GUI 操作
- 工具调用的出错处理：参数错误、调用失败、结果解析

### Agent Capabilities 2: Context Management for Long-Context Agents

**核心问题**：多步交互会不断累积观察和历史，上下文窗口装不下、也用不好时怎么办？

- 长程任务中上下文的来源：系统提示、任务描述、工具返回、交互历史
- 上下文窗口的限制：长度上限、长上下文中的信息丢失（lost in the middle）、推理成本
- 上下文压缩：摘要、截断、对工具输出做过滤
- 按需检索：把信息放在外部，用时再取回上下文（RAG）
- 上下文工程：决定在每一步把什么信息放进上下文

### Agent Capabilities 3: Skills and Memory

**核心问题**：Agent 如何跨任务积累经验，而不是每次从零开始？

- 记忆的分类：短期记忆（当前上下文）与长期记忆（外部存储）
- 情景记忆（经历过什么）与语义记忆（知道什么）
- 记忆的写入、检索与更新
- 技能（Skills）：把可复用的操作流程沉淀为代码或工具
- 从经验中学习：反思（Reflection）与技能库的自我扩充

### Agent Capabilities 4: Planning, Task Decomposition, and Multi-Agent Coordination

**核心问题**：面对复杂的长程任务，如何拆解、规划，并让多个 Agent 分工协作？

- 任务分解：把目标拆成可执行的子任务
- 规划方式：先规划后执行（Plan-and-Execute）、边执行边调整
- 搜索式推理：树搜索、自我验证与回溯
- 多智能体协作：角色分工、编排者–执行者（Orchestrator–Worker）模式
- 多智能体的通信、冲突与一致性问题
