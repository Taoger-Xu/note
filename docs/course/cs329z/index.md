# CS329Z · Engineering AI Agents

Stanford 的 AI Agent 工程课程，关注如何设计、构建和评估基于大语言模型的智能体系统。

## 课程资料

- [课程官网](https://cs329z.stanford.edu/index.html)
- [中文资源](https://cs.xuyili.com/index.html)

## 课程地图

课程从导论出发，先按 Agent 的组成部件逐一构建（LLM 核心、规划、记忆、工具），再组装成框架与多智能体系统；随后用数据、优化与评测形成改进闭环，最后落到安全与真实应用。点击节点可进入对应笔记。
